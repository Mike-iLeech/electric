# ElectricCAD Easy

Абстрактный конструктор временных электросетей: щиты, дистрибьюторы, переходы, потребители, фазы и нагрузка.

Версия 32.7.0 добавляет приложение для macOS: Apple Silicon и Intel, DMG/ZIP, меню и сочетания Command. Установка и ограничения подписи описаны в [MACOS.md](MACOS.md). Расчёты и формат проектов общие с Windows и веб-версией.

При первом запуске открывается демо-проект владельца: 29 модулей, 28 соединений. При последующих запусках восстанавливается локальная сессия. ПКМ на «Импорт» открывает выбор загрузки с диска или повторной загрузки демо; загрузка демо поддерживает отмену.

ПКМ по кабелю открывает настройки, Shift+ПКМ сбрасывает ручную трассу. Для нестандартных номиналов 6–600 А примерное сечение рассчитывается по S(I) = 0,0368 · I^1,3754 с предупреждением ввести точное значение. Стандартные номиналы используют настроенную таблицу сечений.

Живой сайт: https://ileech.mywire.org/electric/.

## Запуск

Откройте index.html в браузере. Для работы приложения не нужны зависимости, сервер или интернет. Альтернатива: node server.cjs → http://127.0.0.1:18744.

node build.cjs создаёт автономный dist/index.html со встроенными CSS/JS. Для публикации достаточно одного файла. Исходники разделены на engine.js, app.js и editor.css.

## Модель

- Новые проекты: Uф = 230 В; Uл = √3 × Uф ≈ 398,37 В. Напряжение редактируется. Импорт v31 сохраняет исходные 220 В.
- PF=1, 50 Гц, симметричный трёхфазный потребитель — явные допущения абстрактной модели.
- Фаза наследуется по текущему графу при каждом расчёте. Порядок сборки не влияет на результат.
- Требуемая нагрузка отделена от фактической. Нет источника или разомкнут автомат → фактические мощность и ток равны нулю.
- В щитах и дистро: вводной и выходные автоматы, номиналы и состояния. 3P размыкает три фазы вместе.
- «Проверить автоматы» выполняет явный шаг пороговой симуляции. Временные характеристики B/C/D и селективность не рассчитываются.
- Кабельные настройки включают длину, сечение, материал, допустимый ток, падение напряжения и потери. Приблизительное сечение требует замены точным значением.

## Редактор

Каталог готовых модулей, справочник разъёмов, реестр связей, поиск, пользовательские шаблоны. Конструктор задаёт тип, 1ф/3ф, вход и отдельно каждый выход: разъём, ток, фазу и автомат. Потребитель настраивается тем же способом. У питаемого модуля один вход. Входы слева, выходы справа, индикаторы нагрузки снизу.

Карточки не перекрываются. Ортогональные провода обходят модули. Поиск имеет конечный бюджет; при отсутствии пути есть сообщение, провод не рисуется через препятствие.

Undo/Redo хранит до 100 действий. Перенос группы и завершённое переименование занимают по одному шагу. Shift+лассо добавляет к выделению. Подсветка порта использует ту же проверку, что создание соединения.

Нет интервальной перерисовки. Используются requestAnimationFrame, DPR, кэш маршрутов. Панели адаптированы под смартфоны и планшеты. На сенсорном экране: последовательные касания портов, перенос модуля, фон одним пальцем для панорамы, pinch и отдельный инструмент лассо.

## Управление

| Действие | Клавиша |
|---|---|
| Начало / вся схема | F / Shift+F |
| Выбор нескольких | Shift+клик / Shift+лассо |
| Копия / вставка / вырезать | Ctrl+C / Ctrl+V / Ctrl+X |
| Отменить / повторить | Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z |
| Удалить / выбрать всё | Delete / Ctrl+A |
| Переместить выбранные | Стрелки; Shift — большой шаг |
| Очистить весь проект | Ctrl+Shift+Alt+Delete |
| Локальная сессия | Ctrl+S |
| Экспорт / импорт JSON | Ctrl+Shift+S / Ctrl+Shift+O |
| Отмена / закрыть окно | Escape |

На macOS поддерживается Cmd. Поля ввода сохраняют обычное поведение клавиш. Разъединение: ПКМ по порту или кнопка «Разъединить порт».

## Сохранение

Сессия хранится в localStorage текущего браузера и origin с предыдущим снимком. file://, localhost, HTTP и HTTPS не делят сессию — переносите проект через JSON. Содержимое проекта не отправляется на сервер.

Импорт v31 мигрируется. Плохие числа, версии, дубли, занятые порты, несовместимые соединения и циклы отклоняются до замены проекта. При ошибке сохраняются активный проект и Redo. Русские имена экспортируемых файлов сохраняются.

## Разработка и проверка

Node.js 20+. Для тестов: pnpm install --ignore-scripts, затем node --test tests/*.test.cjs. Сборка: node build.cjs.

Тесты jsdom проверяют логику с заглушкой Canvas. Дополнительно выполнена визуальная проверка в настоящем браузере при 1280×720 и 390×844; физические сенсорные устройства отдельно не проверялись. Причины проблем viewport, точная модель автоматов и ограничения публикации: [CHANGES-v32.md](CHANGES-v32.md), последующая доработка: [VISUAL-CHANGES.md](VISUAL-CHANGES.md).
