# ElectricCAD Easy

Конструктор электросетей для концертных площадок, мероприятий и любых временных подключений. Схема собирается из типовых узлов — вводы, дистрибьюторы, удлинители и потребители — а приложение в реальном времени считает нагрузку по фазам, подсвечивает перегрузки и дисбаланс фаз.

Одностраничное приложение: один HTML-файл, тёмная тема, работает в любом браузере без сервера и сборки.

**Живая версия:** <https://ileech.mywire.org/electric/>

## Возможности

### Визуальный редактор
- **Бесконечная рабочая область** с мировой системой координат: зум колесом мыши, панорама средней кнопкой, мгновенный фокус на `0;0` (клавиша `F`);
- **Ноды-блоки** с входом и выходами; у каждого порта — свой типоразъём разъёма, номинал (А) и фаза;
- **Соединение портов перетаскиванием** (ЛКМ по овалу порта → овал другого порта), разъединение — ПКМ по порту;
- **Выделение**: одиночное (ЛКМ), групповое (SHIFT+ЛКМ), **лассо** (drag по пустому месту);
- **Буфер обмена**: Ctrl+C / Ctrl+V / Ctrl+X, удаление Del / Alt+Del;
- **Undo / Redo**: Ctrl+Z / Ctrl+Y — полная история действий.

### Каталог оборудования
- **Ввод / Источники**: электрощиты 3P 250/125/63/32/16A, трёхфазные розетки CEE, однофазные CEE 32/16A, EURO/SHUKO 16/10/6A;
- **Дистрибьюторы**: трёхфазный → трёхфазный (250→2×125, 125→2×63, 63→2×32, 32→2×16A) и трёхфазный → однофазный с распределением по фазам **L1/L2/L3** (32A→6×16A CEE, 32A→6×16A EURO, 16A→3×16A EURO);
- **Удлинители / Переходы**: EURO 1→5×16A, CEE 16A 1ф → 5×EURO 16A;
- **Потребители**: однофазные EURO, CEE 1ф и трёхфазные CEE с заданным потреблением (Вт);
- **Создание своей ноды** любой конфигурации (тип, разъёмы, номиналы, количество выходов, потребление).

### Расчёт нагрузки (в реальном времени)
- Автоматический пересчёт при любом изменении схемы;
- Потребление потребителей раскладывается по фазам **L1/L2/L3**; трёхфазные потребители делятся равномерно;
- Перевод мощности в ток: 230 В для однофазных, 400/√3 В для трёхфазных цепей;
- **Индикация загрузки цветом**: зелёный → жёлтый → **красный при перегрузке** (превышение номинала порта);
- **Детектор дисбаланса фаз**: разница ≥ 1,5× между фазами подсвечивается на трёхфазных узлах.

### Правила корректности схемы
Приложение не даёт собрать заведомо неверную схему:
- запрет соединений выход↔выход и вход↔вход;
- запрет соединения **разных типоразъёмов** разъёмов и **разной фазности**;
- запрет **циклов** в схеме;
- запрет подключения к **занятому выходу**.

### Проекты
- Название проекта, автосохранение в браузере (localStorage);
- **Экспорт / импорт JSON** (кнопки или Ctrl+Shift+S / Ctrl+Shift+O) — переносите проекты между устройствами;
- Очистка проекта;
- Встроенная **справка (HELP)** по управлению и правилам.

## Как это работает

1. Выберите узел в каталоге (или создайте свой) — он появится в центре рабочей области;
2. Перетащите овал выходного порта на овал входного порта следующего узла;
3. Повторяйте, пока не построите цепочку «щит → дистрибьютор → потребитель»;
4. Наблюдайте за нагрузкой на каждом порту и цветом индикации.

## Запуск

Просто откройте `index.html` в браузере. Никаких зависимостей и установки — всё (включая сохранение проектов) работает локально, без интернета.
