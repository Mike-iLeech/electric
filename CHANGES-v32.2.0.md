# ElectricCAD Easy 32.2.0

- Компактные уведомления с цветами по типам и подтверждение вставки.
- Улучшенное окно экспорта с инспектором справа и редактированием основной надписи.
- Масштабирование и панорамирование чёткого превью с кэшированием команд рисования.
- Последовательные номера веток и трасс, упорядоченный кабельный журнал по веткам.
- Заполнение столбцов журнала по высоте на форматах A4–A0 и масштабирование значков.
- Зазоры кабелей от модулей и дополнительный поиск обходных маршрутов печатной схемы.
- Адаптивное разрешение PNG/JPEG по масштабу схемы, прямой рендер без увеличения превью.
- Блокировка зума во время панорамирования средней кнопкой мыши.

Windows x64: установщик и автоматические обновления из GitHub Releases. Выпуск без цифровой подписи.
