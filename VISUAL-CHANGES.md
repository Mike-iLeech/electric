# Доработка по замечаниям к дизайну

## Внешний вид

Восстановлены цвета v31 и ширина капсулы 354: белый щит, красный трёхфазный CEE, синий однофазный CEE, светлый Schuko, жёлто-оливковый дистрибьютор, зелёный удлинитель, синий потребитель. Название, тип, разъёмы, фазы и нагрузки снова находятся в отдельных капсулах исходного оформления. Новые параметры автоматов используют ту же систему капсул.

Порядок внутри модуля: подложка → все капсулы/текст/нагрузки → пины и их короткие выводы. Геометрия капсулы порта общая для рисования и попадания.

## Слои и движение

Статичная сетка находится на Canvas, провода — в отдельном SVG-слое. Каждый видимый модуль имеет кэшированное прозрачное изображение; модульный слой располагается над проводами. Предпросмотр соединения и лассо отделены от статичной схемы.

Перемещение меняет CSS transform готового модуля. Капсулы и фон не перерисовываются. Провода не скрываются: связанные SVG-пути и затронутые дуги обновляются во время движения. Отдельный тест проверяет 20 шагов переноса без роста счётчиков modulePaints/staticPaints, с непрерывно видимым связанным проводом. Изображения вне viewport освобождаются, разрешение кэша зависит от масштаба и DPR. Правила пучков и скольжения: [ROUTING.md](ROUTING.md).

## Соединения

Маршрутизатор учитывает уже занятые дорожки, разводит параллельные отрезки с зазором 12 мировых единиц и обходит капсулы. Перпендикулярные пересечения на прямых участках получают дугу-перемычку с просветом; касание пина не обозначается как пересечение. Углы уже проложенных проводов обходятся, чтобы не создавать ложный узел. В очень плотной схеме возможен отказ поиска — тогда показано сообщение, а линия через препятствие или поверх занятой дорожки не используется как запасной вариант.

## Панели и каталог

Слева: один компактный ряд Назад/Сохранить/Экспорт/Импорт/Очистить → название проекта → GENERAL Settings с фазным и линейным напряжением → каталог и «Создать свой модуль». Изменение любого напряжения пересчитывает второе через √3.

Справа: Outliner сверху, свойства и настройки выбранного модуля ниже. В Outliner можно выбрать несколько модулей, двойным нажатием центрировать модуль. Секции сохраняют раскрытие при обновлении.

Каталог содержит 132 шаблона, все проходят валидацию:

- Вводы → Щиты → С розеткой → Трёхфазные / Однофазные → CEE / Shuko.
- Вводы → Щиты → С автоматом (клеммный ввод) → Трёхфазные / Однофазные.
- Вводы → Розетки → Трёхфазные / Однофазные → CEE / Shuko; дополнительные поддерживаемые семейства сохранены.
- Дистрибьюторы.
- Переходные коробки и кабели, включая голые концы → CEE / Schuko / Powercon и фазные ответвления.
- Удлинители → CEE–SHUKO ×5 / SHUKO–SHUKO ×5 / Powercon–SHUKO ×5.
- Потребители → фазность → тип входа.

В каждом разделе есть группировка по номиналу, числовая сортировка и поиск. Поддерживаемое семейство разъёма остаётся абстрактным, без подтверждения конкретного изделия.

## Проверка

80 тестов проходят: расчёты, сохранение, редактор, порядок слоёв, цвета, геометрия портов, разнесение проводов, дуги, структура каталога и отсутствие перерисовок при переносе.

Лассо выбирает по пересечению и появляется после порога движения 5 экранных пикселей. Обычный клик не показывает старую рамку; клик на члене группы выбирает его отдельно, перетаскивание сохраняет группу. Создание из каталога ищет свободное место в видимой области; при заполнении камера показывает новый модуль. Шаг портов увеличен до 44, проверены тексты всех 132 шаблонов и максимального пользовательского модуля. Поля свойств и кнопки разнесены. Перегруженные модули, питающие их линии и подключённые порты мигают через CSS без перерисовки схемы; при reduced-motion индикация статическая.

Настоящий браузерный предпросмотр проверен по HTTP на 127.0.0.1:18744: исходные капсулы и сайдбары при 1280×720, левая панель при 390×844, выбор через Outliner и крупный вид дистрибьютора. Это проверка размеров viewport, не испытание физического сенсорного устройства. Предыдущее ограничение file:// остаётся, но не препятствует ограниченному HTTP-предпросмотру. Продуктивный сайт не изменялся.

Автономная сборка: `node build.cjs` → `dist/index.html`. Исходники отрисовки: `renderer.js`, восстановленные стили: `original-theme.css`.
