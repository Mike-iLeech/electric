# ElectricCAD Easy 32.7.0

- Порт macOS: отдельные DMG/ZIP для Apple Silicon и Intel, общая иконка приложения.
- Меню приложения, Cmd-сочетания клавиш, редактирование текста/схемы и повторное открытие из Dock.
- Локальные данные в Library/Application Support, отдельные от приложения.
- Нативные macOS CI и проверки архитектуры, подписи, образов, сохранения и экспорта.
- Mac-файлы выпускаются с ad-hoc подписью и устанавливаются/обновляются вручную; сертификата Apple Developer ID и нотарификации пока нет. Проверки безопасности ОС не отключаются.
