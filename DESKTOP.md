# ElectricCAD Easy для Windows

Версия для Windows содержит ту же схему, каталог, расчёты, экспорт и справку, что и веб-приложение. Все ресурсы включены в приложение; для работы со схемой подключение к интернету не требуется.

## Установка и запуск

1. Запустите `ElectricCAD-Easy-32.1.1-Setup-x64.exe` из папки `release`.
2. Выберите папку установки. По умолчанию приложение устанавливается для текущего пользователя в `%LOCALAPPDATA%\Programs\ElectricCAD Easy`; права администратора не требуются.
3. После установки используйте ярлык **ElectricCAD Easy** на рабочем столе или в меню «Пуск».

Поддерживаются Windows 10 и 11, 64-разрядная архитектура x64. Устанавливать Node.js, браузер или отдельный сервер на компьютер пользователя не нужно. Каталог `release\win-unpacked` — готовое приложение без установщика: для запуска нужен весь каталог вместе с `ElectricCAD Easy.exe`.

Локальная тестовая сборка пока не подписана сертификатом издателя. Windows может показывать предупреждение о неизвестном издателе. Для доверенной подписи нужен сертификат Code Signing или настроенный сервис Azure Artifact/Trusted Signing; самоподписанный сертификат не заменяет доверенную подпись.

## Пользовательские данные

Данные отделены от файлов программы и хранятся в `%APPDATA%\ElectricCAD Easy` (обычно `C:\Users\<имя>\AppData\Roaming\ElectricCAD Easy`).

| Каталог / файл | Назначение |
|---|---|
| `Projects\current.json` | Текущая схема, записываемая автосохранением и кнопкой «Сохранить» |
| `Backups\previous.json` | Предыдущая сохранённая версия текущей схемы |
| `Settings\custom-modules.json` | Пользовательские шаблоны модулей |
| `Settings\ui.json` | Настройки интерфейса |
| `Settings\application.json` | Язык приложения и параметры проверки обновлений |
| `Exports` | Папка для экспорта по умолчанию; при сохранении можно выбрать другую |
| `Browser` | Служебный профиль встроенного браузера |

Папку данных можно открыть из меню приложения. Обновление сохраняет пользовательские данные. В мастере удаления есть выключенный по умолчанию флажок **«Удалить данные приложения»**. Без него папка данных остаётся; с ним удаляются проекты, резервные копии, модули, настройки и экспорт из `%APPDATA%\ElectricCAD Easy`, а также служебный кэш обновлений `%LOCALAPPDATA%\electriccad-easy-updater`. При обновлении или тихом удалении (`/S`) данные не удаляются. Папка, заданная через `ELECTRICCAD_DATA_DIR`, не удаляется автоматически. Для ручной резервной копии закройте приложение и скопируйте всю папку `%APPDATA%\ElectricCAD Easy`.

Веб-версия и EXE используют разные хранилища. Для переноса схемы из браузера нажмите **Скачать проект**, затем в Windows-приложении нажмите **Импорт** и выберите JSON. Пользовательские модули переносятся отдельно кнопками экспорта и импорта в каталоге модулей.

## Сборка разработчиком

Требуются Windows x64, Node.js 22.12 или новее и pnpm 11.25.0. Версии Electron и electron-builder закреплены в `package.json` и lock-файле.

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm desktop:build
```

Первый запуск загружает Electron и инструменты упаковки из официальных репозиториев. Команда `pnpm desktop:build` сначала создаёт автономный `dist/index.html`, затем формирует приложение и NSIS-установщик в `release`. Автоматическая публикация отключена.

```powershell
pnpm desktop:start  # запуск исходников в Electron
pnpm desktop:dir    # сборка release/win-unpacked без установщика
node scripts/desktop-smoke.cjs  # два запуска, автосохранение и JSON/PDF/PNG/JPG
```

Electron работает с изоляцией контекста, отключённым Node.js в странице и sandbox. В дистрибутив входят только автономный HTML, desktop-оболочка, иконка и лицензии; тесты, исходные GIF и зависимости сборки в него не попадают.

Конфигурация установщика: `electron-builder.cjs`. `oneClick:false` включает мастер установки, `perMachine:false` и `allowElevation:false` оставляют установку в пределах текущего пользователя. `deleteAppDataOnUninstall:false` отключает безусловное удаление данных; отдельный необязательный компонент в `desktop/assets/installer.nsh` удаляет только две фиксированные папки данных и кэша после выбора пользователем. Скрытый аргумент `--delete-app-data` не поддерживается, чтобы его нельзя было использовать вместо флажка.

Для тестирования можно задать `ELECTRICCAD_DATA_DIR` абсолютным путём к отдельной папке: так проверка не затрагивает рабочую схему пользователя.

Smoke-тест создаёт собственную папку в `test-results`, закрывает приложение сразу после изменения проекта, затем запускает его заново и проверяет проект, настройки и экспорт четырёх форматов. Скриншоты и выгрузки остаются в этой тестовой папке. Windows CI также собирает установщик и прикладывает его как артефакт `ElectricCAD-Easy-Windows-x64-preview`.


## Настройки и обновления

Окно **Настройки** содержит язык и параметр автоматической проверки обновлений. При включённой опции приложение проверяет стабильные релизы `Mike-iLeech/electric` раз в семь дней; срок сохраняется между запусками. Если приложение было закрыто, просроченная проверка выполняется при следующем запуске. Кнопка ручной проверки не требует ожидания недели. Обновление не закрывает редактор самопроизвольно: установка запускается пользователем после загрузки.

Для обновлений используются `electron-updater` и три файла одного релиза: `ElectricCAD-Easy-<версия>-Setup-x64.exe`, соответствующий `.blockmap` и `latest.yml`. Их создаёт `pnpm desktop:build`. Обновления поддерживаются без сертификата издателя. Сборка с настроенным издателем проверяет его подпись. Для перехода с версии 32.1.0 установите 32.1.1 вручную.

## Подписанный выпуск

`pnpm desktop:release` проверяет наличие конфигурации подписи, собирает NSIS с `forceCodeSigning:true`, затем проверяет подписи EXE и установщика через `Get-AuthenticodeSignature`. Проверка требует `Status=Valid`, точное имя издателя (CN) и метку времени; неподписанный или самоподписанный файл не публикуется. Успешная проверка создаёт `release/SHA256SUMS.txt`.

Имя издателя задаётся в `ELECTRICCAD_PUBLISHER_NAME` и должно точно совпадать с CN сертификата. Поддерживается один из способов:

- PFX: `CSC_LINK` / `CSC_KEY_PASSWORD` (или стандартные `WIN_CSC_LINK` / `WIN_CSC_KEY_PASSWORD`). Значения находятся только в окружении и не записываются в репозиторий.
- Хранилище сертификатов Windows: `ELECTRICCAD_CERTIFICATE_SHA1` с отпечатком сертификата, содержащего доступный закрытый ключ.
- Azure: `ELECTRICCAD_AZURE_ENDPOINT`, `ELECTRICCAD_AZURE_ACCOUNT`, `ELECTRICCAD_AZURE_PROFILE` и стандартные переменные аутентификации `AZURE_TENANT_ID`, `AZURE_CLIENT_ID`, `AZURE_CLIENT_SECRET`.

В GitHub Actions workflow **Windows release** запускается вручную для main. По умолчанию он выпускает сборку без подписи. Для подписанного выпуска включите signed и настройте издателя и секреты в окружении desktop-release. Перед новым выпуском увеличьте package.json.version.
