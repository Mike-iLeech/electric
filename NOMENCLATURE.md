# Обозначения модулей

Отображаемое имя: `Название | Однофазный (P+N+PE) или Трёхфазный (3P+N+PE) | Вход -> Выход`. Номенклатура едина для каталога, Outliner, капсул, свойств и печатной схемы. Пользовательское имя остаётся редактируемым; электрические части обозначения формируются по портам и мощности. Старые штатные названия распознаются без замены ID и связей. Слова цвета в именах CEE удалены; однофазный CEE обозначается P+N+PE.

Клеммные источники без щита исключены из штатного каталога. Существующие клеммные источники при чтении проекта становятся щитами с вводным автоматом; ID узла и портов сохраняются. Создание нового клеммного источника также автоматически включает щит. Переходные кабели с голыми концами остаются отдельной категорией.

Клеммный порт: пилюля, окантовка по фазности, три или пять прямоугольных контактов. Однофазный — синяя окантовка, трёхфазный — красная. По выбранной владельцем палитре L1 белый, L2 чёрный, L3 коричневый, N голубой, PE жёлто-зелёный. Щит остаётся белым. Отдельное кольцо перегрузки у контакта не рисуется; сигнализирует весь сокет.
