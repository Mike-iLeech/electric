# ElectricCAD Easy 32.4.0

- Обновления, язык и данные PC встроены в общую страницу настроек.
- Настройки и открытие папки данных стоят рядом под кнопками проекта.
- Одно редактируемое поле cos φ — коэффициент мощности, с пояснением в справке.
- cos φ учитывается в токах, проверках перегрузки, потерях и доступной активной мощности. Падение напряжения оценивается по активному сопротивлению; гармоники и реактивное сопротивление не моделируются.
- После успешного сохранения схемы PC показывает путь и кнопку открытия файла. Доступ к открытию ограничен завершёнными экспортами.
- В поддерживаемых браузерах экспорт использует системное сохранение с подтверждением; браузер не раскрывает полный путь.

Windows x64. Обновление из GitHub Releases, без цифровой подписи. Пользовательские данные сохраняются.
