# ElectricCAD Easy 32.3.0

- Общее окно настроек в веб- и PC-версии, параметры мира и режимы работы.
- Температура, материал, предел падения напряжения и тепловое сопротивление кабелей по умолчанию; индивидуальные параметры имеют приоритет.
- Сечения кабелей в двухстрочной таблице, автосохранение и сброс рядом с заголовком.
- Допущения модели раскрываются в настройках со ссылкой на справку.
- Команды автоматов, перестройки трасс и авторасстановки вынесены в тулбар.
- Окно «Управление» рядом с «Помощь»: мышь, жесты и клавиатура.
- Убрана лишняя верхняя строка; WORLD справа в пилюле, крупное «Итого» в свободной области при скрытой правой панели.

Windows x64: обновление через GitHub Releases, без цифровой подписи. Пользовательские данные сохраняются.
