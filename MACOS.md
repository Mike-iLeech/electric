# ElectricCAD Easy для macOS

Доступны отдельные DMG и ZIP для Apple Silicon (`arm64`) и Intel (`x64`). Выбирайте архитектуру своего Mac; Rosetta для ARM-сборки не нужна. В DMG перетащите `ElectricCAD Easy.app` в «Программы».

Первый порт имеет локальную ad-hoc подпись, без сертификата Apple Developer ID и нотарификации. Gatekeeper может ограничивать запуск загруженного приложения. Системные проверки безопасности приложение не отключает. Для выпуска с подтверждённым издателем нужна отдельная настройка Apple Developer ID и нотарификации. Сборка проверяет целостность подписи, но это не равнозначно одобрению Gatekeeper.

Обновление этой macOS-сборки ручное: скачайте DMG новой версии с GitHub и замените приложение в «Программах». Встроенная установка обновлений здесь отключена; проверки подписи не обходятся. Windows продолжает использовать штатное автообновление.

## Работа

- Cmd+S сохраняет проект; Cmd+Z / Cmd+Shift+Z отменяют и повторяют изменения.
- Меню «Правка» использует обычное редактирование для текстовых полей и команды схемы вне них.
- Закрытие главного окна скрывает его. Нажатие на значок Dock снова открывает редактор. Cmd+Q завершает приложение.
- Проекты и настройки: `~/Library/Application Support/ElectricCAD Easy`. Папка отделена от `.app` и сохраняется при его замене. Перед переносом на другой компьютер экспортируйте JSON.
- Веб-версия и приложение имеют отдельные хранилища.

## Сборка на Mac

```sh
pnpm install --frozen-lockfile
pnpm desktop:mac
```

Для одной архитектуры:

```sh
pnpm build
pnpm exec electron-builder --config electron-builder.cjs --config.compression=normal --mac --arm64 --publish never
node scripts/mac-verify.cjs arm64
```

Для Intel замените `--arm64` на `--x64`, аргумент проверки — на `x64`. Иконка ICNS создаётся упаковщиком из общей PNG-иконки.

CI собирает и проверяет обе архитектуры на нативных macOS 15 раннерах: тесты, два запуска Electron с сохранением/чтением и экспортом, DMG/ZIP, архитектуру Mach-O, версию приложения, ICNS и целостность подписи. Затем запускается готовый подписанный `.app` с изолированными данными: проверяются загрузка редактора, preload, sandbox и ручной режим обновлений. Скриншоты smoke могут быть недоступны из-за compositor GitHub runner; это не заменяет ручную визуальную проверку на Mac.

Выпуск: после слияния PR и зелёного CI существующий `Windows release` создаёт релиз версии из package.json. Затем `macOS release` с тем же тегом собирает Mac-файлы из этого тега и добавляет их в опубликованный релиз. Существующие опубликованные файлы не перезаписываются; macOS-manifest автообновления не публикуется до появления полноценной подписи издателя.

Основание платформенной адаптации: [Electron application menu](https://www.electronjs.org/docs/latest/tutorial/application-menu), [electron-builder v26 macOS](https://www.electron.build/v26/docs/mac/), [официальные метки GitHub macOS runners](https://github.com/actions/runner-images).
